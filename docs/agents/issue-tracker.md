# Issue tracker: Local Markdown

Store issues and specifications under `.scratch/<feature>/`.

- Specification: `spec.md`.
- Tickets: `issues/<NN>-<slug>.md`, numbered from 01.
- Use one file per ticket.
- Record triage state in a `Status:` line near the top.
- Use the labels defined in `triage-labels.md`.
- Append discussion under `## Comments`.

When asked to publish an issue, create its local Markdown file.
When asked to fetch a ticket, read the referenced file.
