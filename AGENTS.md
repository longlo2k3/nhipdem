# Training

Build a Vietnamese personal workout tracker using the schedule in `workout-plan.js`.
Preserve the user's prescribed exercises, sets, and repetition ranges when changing the app.

The iOS/Android app lives in `mobile/` and uses Expo + React Native.
After editing `workout-plan.js`, run `npm run mobile:sync` to update its native copy.
Before changing cloud build or MCP integration, read `docs/ios-build.md`.

## Agent skills

### Issue tracker
Track work in local Markdown files. Read `docs/agents/issue-tracker.md`
before creating or updating issues.

### Triage labels
Use the five default labels. Read `docs/agents/triage-labels.md`
before classifying issues.

### Domain docs
Use a single-context layout. Read `docs/agents/domain.md`
before exploring or changing the project.
